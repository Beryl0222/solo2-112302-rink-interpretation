# 冰球判罚笔录的多语复议与比赛恢复

这是面向“判词、停表摘录与复议来文”业务文本的 Python 项目。当前目录提供合成练习语料和已登记的原始记录，记录用于开发与回归时复核文字内容和来源关系。

## 内容

- data/corpus.json 保存合成文本记录及记录类别。
- data/context.json 说明当前语料范围。
- materials.py 读取项目语料，保留每条记录的原始文字。
- penalty_review/ 复议席处理包：
  - lexicon.py 多语词表（队名别名、罚种、处罚类别、决定动词、语气标记）。
  - parsing.py 把判词、口译、时钟摘录、领队异议与已发界面解析为结构化对象，逐句标注决定语气（确认/转述/申请）。
  - review.py 核对确认与印证、保留对象歧义的待复核分叉、按节次与倒数时钟核对停表窗口，并判定更正影响的是计时中的主罚、排队的后续罚还是替代服罚人。
  - resumption.py 生成比赛恢复记录：已走时间不重播，保留仍有约束的判罚，重新确定后续起算与可上场人员；分叉不写入可执行行。
  - bulletin.py 生成对外双语通报，只反映裁决成立的部分，留存已发界面与出处。
  - pipeline.py 端到端流程。
- tests/ 检查资料读取入口、语料索引的完整性，以及复议与恢复规则。

## 运行和检查

项目仅依赖 Python 标准库。运行检查：

    python3 -m unittest discover -s tests -v

查看当前语料的复议后恢复通报：

    python3 -m penalty_review
